# CoachBubble

Paused: hidden in the current build. Kept for when guidance returns.


Lumi's guidance for the current page. It sits directly under the page heading, holds up to three short tips, and updates as the user types.

- `surface` fill, `line` border, radius `r-surface`, padding `s-3` `s-4`, max width 720px.
- 36px mascot avatar left; a 12px `muted` label ("Lumi 建议") above the tips.
- Each tip names one gap and one next move. No praise, no exclamation marks.
- Hidden on settings, support and publish pages.
