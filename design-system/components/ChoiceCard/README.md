# ChoiceCard

A large selectable option for setup questions such as "这次讲给谁". Two lines: a 14px/600 title and a 12px `muted` hint.

- Min height 64px, padding `s-3` `s-4`, radius `r-control`, `line` border on `surface`.
- Hover: `soft` background. Selected: `ink` border and `selected` fill.
- Lay out in a wrapping row with gap `s-2`.
