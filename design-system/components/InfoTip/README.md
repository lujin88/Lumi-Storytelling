# InfoTip

An ⓘ at the end of a page intro (help triggers trail their text; status icons lead) that holds secondary text: where a method comes from, what the labels mean.

- Trigger: Material `info`, 16px, `muted`, turns `ink` on hover or focus. 24px hit area.
- Panel: `surface`, `line` border, `r-control`, soft shadow, 12px text, padding `s-2` `s-3`. Hugs its content on one line up to 360px. A small caret points at the icon.
- Opens on hover and keyboard focus; stays open while the pointer is inside so links can be clicked. Links use `info` with an `info-line` underline.
