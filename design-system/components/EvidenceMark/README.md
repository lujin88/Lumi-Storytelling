# EvidenceMark

Flags a slide or follow-up that needs action. Shown only for two states; supported and stated-only show nothing.

| state | icon (Material) | text | color |
|---|---|---|---|
| inferred | `help` | 待确认 | `info` |
| missing | `error` | 缺材料 | `danger` |

Icon 16px + 12px/500 text, gap 4px, no border or fill. A tooltip says what to do. Missing cards also get a dashed border.
