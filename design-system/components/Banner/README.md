# Banner

A one-line status under the page title or a section label. No fill, no border: icon + text + optional text link.

- Warning: Material `warning` (triangle), `danger` text. Example: 结构还没确认 … 去确认结构.
- Done: Material `check_circle`, `ok` text.
- Icon 16px leads the text, gap 8px, 13px text. The action is a text link after the sentence.
